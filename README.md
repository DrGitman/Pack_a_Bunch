# Pack-a-Bunch

The website for Pack-a-Bunch, an Android app that helps you organise your things, plan how they fit into a space, and follow a step-by-step packing guide.

Built with React, JavaScript, and Vite, the site introduces the app, explains its features and plans, and provides an Android download.

## Features

- Responsive layouts for phones, tablets, and desktops
- App screenshots and product showcases
- Subtle scroll animations and hover interactions
- Accessible navigation, keyboard controls, and reduced-motion support
- Plan comparison, frequently asked questions, and app download instructions

## Getting started

Use Node.js 22.12 or newer.

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

The production website is generated in `dist/`.

## Tests

```sh
npm test
```

Browser tests use Playwright and Microsoft Edge to check responsive layouts, accessibility, navigation, animations, and downloads.
